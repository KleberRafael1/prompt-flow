# ⚡ PromptFlow

> Desafio Criativo DIO — Acelerando Sua Produtividade Pessoal com IA

## 📌 Sobre o projeto

O **PromptFlow** é um exercício de Engenharia de Prompts desenvolvido como parte do **Desafio Criativo da DIO**.

A proposta é demonstrar como uma necessidade cotidiana pode ser transformada em um **prompt claro, estruturado e útil para Inteligência Artificial**.

Neste projeto, o objetivo é utilizar a IA como apoio para **organizar, priorizar e planejar tarefas**, tornando a rotina mais simples e produtiva.

## 🎯 Objetivo

Construir um prompt capaz de orientar uma IA na organização de uma lista de tarefas, considerando:

* Prioridade;
* Urgência;
* Importância;
* Esforço necessário;
* Prazos informados;
* Ordem de execução.

O objetivo é ajudar o usuário a identificar **o que deve ser feito primeiro**, evitando planejamentos desnecessariamente complexos.

## 🧩 Construção do Prompt

O prompt foi desenvolvido em três etapas:

### 1. Definição da intenção

Primeiro foi definido **o que a IA deveria fazer e qual resultado deveria proporcionar**.

> Organizar uma lista de tarefas pessoais e profissionais para ajudar o usuário a definir prioridades e administrar melhor seu tempo.

### 2. Contexto e restrições

Em seguida foram adicionados:

* Contexto de tarefas com diferentes níveis de prioridade;
* Limitação de tempo;
* Critérios para organização;
* Formato esperado da resposta;
* Restrições para evitar informações inventadas.

### 3. Prompt final

As informações das etapas anteriores foram reunidas em um único comando, buscando tornar a instrução clara, objetiva e reproduzível.

## 🤖 Prompt

```text
Quero que a IA organize uma lista de tarefas pessoais e profissionais, com o objetivo de ajudar o usuário a definir prioridades e administrar melhor seu tempo.

Considere o seguinte contexto: o usuário possui diversas tarefas com diferentes níveis de urgência e importância, mas tem tempo limitado durante o dia. O conteúdo deve ter formato de lista organizada por prioridade, indicando o que deve ser feito primeiro e sugerindo uma ordem de execução. Considere a urgência, a importância, o esforço necessário e os possíveis prazos informados pelo usuário.

Evite criar tarefas que não foram informadas, assumir prazos inexistentes ou tornar o planejamento excessivamente complexo. Quando alguma informação importante não estiver disponível, sinalize a ausência do dado em vez de inventar uma informação.
```

## 💡 Aprendizado

O principal aprendizado deste desafio é compreender como **contexto, intenção e restrições** podem transformar uma instrução genérica em um prompt mais eficiente.

Um prompt bem estruturado ajuda a IA a compreender:

**O que fazer + Para quem + Com qual objetivo + Em qual contexto + Como responder + O que evitar**
